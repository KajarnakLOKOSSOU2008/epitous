01 Vision & Philosophie

EpiTous n'est pas un guide. C'est une structure complète de travail et d'apprentissage. L'objectif ultime n'est pas de faire réussir l'étudiant grâce à EpiTous. C'est de lui apprendre à réussir sans EpiTous.

EpiTous est une plateforme pédagogique interactive qui accompagne un débutant complet dans son apprentissage de la programmation et dans son travail quotidien. Elle combine cours progressifs, vidéos, documentation, recherche guidée, exercices, environnement de pratique, debugging, journal d'apprentissage, suivi de progression et assistance intelligente.

Son premier parcours est conçu autour de la Piscine Epitech : l'étudiant commence sans prérequis, apprend les fondamentaux de l'informatique, Unix et C, découvre ensuite les contraintes spécifiques de son environnement pédagogique, puis applique progressivement ses connaissances aux tâches de la Piscine.

🌱 La courbe d'autonomie

L'assistance diminue progressivement jusqu'à l'autonomie complète :

🟢 Débutant : "Voici quoi faire."
🟡 Intermédiaire : "Voici les ressources. Choisis."
🟠 Avancé : "Voici ton objectif. Organise ton travail."
🔵 Autonome : "Voici le problème. Résous-le."

03 Glossaire essentiel

CUnixGitGénéral

Variable

Une variable est un espace de mémoire qui stocke une valeur. En C, on doit déclarer le type : int age = 25;

C

Pointeur

Un pointeur est une variable qui stocke l'adresse mémoire d'une autre variable. int *ptr = &x; — ptr contient l'adresse de x. On déréférence avec *ptr pour accéder à la valeur.

C

Fonction

Bloc de code réutilisable qui prend des paramètres en entrée et retourne une valeur. int add(int a, int b) { return a + b; }

Unix

Terminal

Interface texte qui permet d'interagir avec le système d'exploitation via des commandes. Exemples : ls, cd, mkdir.

Unix

Compilation

Processus qui transforme le code source (C) en un exécutable. gcc main.c -o program produit un fichier program qu'on peut exécuter.

C

Makefile

Fichier qui automatise la compilation. Contient des règles qui décrivent comment compiler le projet. make exécute la première règle.

Git

Commit

Un instantané (snapshot) de ton code à un moment donné. git commit -m "message" sauvegarde les modifications avec un message descriptif.

Git

Branch (Branche)

Une ligne de développement parallèle. git branch feature crée une branche nommée "feature" pour travailler sans impacter la branche principale.

Général

Fichier vs Dossier

Un fichier stocke des données (code, image, texte). Un dossier (directory) contient des fichiers et d'autres dossiers, organisant la structure.

Unix

Chemin (Path)

Localisation d'un fichier ou dossier dans l'arborescence. Absolu : /home/user/projet. Relatif : ../projet.

04 Error Lab — Erreurs courantes

segmentation fault (core dumped)

Erreur de segmentation

Cause : Ton programme accède à une zone de mémoire interdite — souvent un pointeur non initialisé, un accès hors limites d'un tableau, ou un déréférencement de pointeur NULL.

Debug :

  • Vérifie tous tes pointeurs — sont-ils initialisés ?
  • Vérifie les bornes de tes tableaux (index 0 à n-1, pas n)
  • Utilise valgrind ./program pour trouver la ligne exacte
  • Vérifie que tu ne déréférences pas un pointeur NULL
undefined reference to `main'

Référence non définie à main

Cause : Le compilateur ne trouve pas la fonction main. Soit elle n'existe pas, soit elle est mal orthographiée, soit tu compiles le mauvais fichier.

Debug : Vérifie que tu as int main(void) ou int main(int argc, char **argv) dans ton fichier C.

implicit declaration of function 'printf'

Déclaration implicite de fonction

Cause : Tu utilises une fonction sans avoir inclus le header qui la déclare. Pour printf, il faut #include <stdio.h>.

Debug : Ajoute le #include approprié en haut de ton fichier.

make: *** No rule to make target

Pas de règle dans le Makefile

Cause : Le Makefile ne contient pas de règle pour la cible demandée, ou il y a une faute de frappe dans le nom de la cible.

Debug : Vérifie ton Makefile — les tabulations (pas d'espaces !) et les noms de cibles.
